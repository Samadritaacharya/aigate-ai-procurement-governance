# Security and responsible-use boundaries

The repository is a public portfolio implementation using synthetic scenarios. Do not enter confidential contracts, personal employee/candidate data, production credentials, vendor secrets or customer records into a public deployment.

The demo does not perform a legally binding AI Act classification, DPIA, procurement approval, security accreditation or conformity assessment. It is an explainable screening and workflow-design reference.

Productionization would require organization-specific identity, RBAC, SSO, tenant isolation, encrypted persistence, secrets management, DLP, audit retention, legal review, security controls, connector permissions, data-processing agreements and incident response.
